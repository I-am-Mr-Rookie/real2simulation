# S24i music bed

No downloaded track. A clearly licensed Pixabay/CC0 track was not fetched in this run (time-boxed; Pixabay Music pages need a browser session to resolve a direct file URL), so the brief's fallback was used.

| Field | Value |
|---|---|
| Title | S24i soft pad (synthesized) |
| Author | Generated by ffmpeg in media/edit/S24i/build.py (project-authored) |
| URL | none (synthesized locally) |
| Licence | Project-authored; no third-party rights, no credit needed |

Recipe: sines at 110, 164.81, 220, 277.18 Hz plus a slowly swelling 246.94 Hz (A add9), tremolo 0.15 Hz, low-pass 1.2 kHz, two short echoes, fade in 1 s, fade out 2 s. Mixed at -21 dB and ducked under the voice with sidechaincompress (threshold 0.02, ratio 20, attack 20 ms, release 400 ms).
