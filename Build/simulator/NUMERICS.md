# Fixed-step synthetic simulator models

- RK4 validates all four actual stage states and derivatives before its final weighted mean. Slopes are normalized before summing to avoid intermediate overflow, and the timestep is never divided by six before multiplication. A midpoint computes `dt*k/2` normally, but if `dt*k` overflows it uses `dt*(k/2)` so a representable half-stage is not rejected. The fallback is not used for subnormal products/slopes. This is finite binary64 arithmetic, not arbitrary precision.
- Ramp acceleration is `g * (sin(angle) - mu * cos(angle))`, the same operation order as the accepted S08 reference. Preflight requires strictly positive acceleration with no invented epsilon; zero/negative acceleration remains unsupported. Near cancellation, relative physical accuracy is ill-conditioned even when the represented acceleration is positive.
- Pendulum dynamics now follow the existing `analyticComparison.model` selector. For the declared `small-angle-linearized` domain (`hypot(theta0, omega0/sqrt(g/L)) <= 0.1 rad`), RK4 solves `theta'' = -(g/L)*theta`, exactly the S08 model. The model conserves `L^2*omega^2/2 + g*L*theta^2/2`; it does **not** conserve the full nonlinear `g*L*(1-cos(theta))` energy. Circular position/velocity mapping is retained as the reference specifies. No horizon/amplitude rejection or Gate P tolerance change was introduced.
- The pre-existing `nonlinear-only` domain retains `theta'' = -(g/L)*sin(theta)`, nonlinear energy, and no claim of a linear analytic comparison. The dynamics switch uses the existing advertised model, not a special fix for one amplitude or frozen case. Finite-angle physics is not claimed for the linear approximation.

The frozen R14 audit contains nonlinear-energy controls for small-angle inputs. Those diagnostics were appropriate for the old nonlinear implementation but conflict with the accepted linear-model correction. They remain unchanged and are reported explicitly alongside independent linearized-energy/analytic tests. The Gate P oracle, fixture inputs and `0.005` tolerance remain unchanged. None of these synthetic numerical checks establish physical Gate M, browser rendering, contacts or S12 readiness.

## Independent invariant justification

The accepted S08 source (`Build/templates/pendulum.py`, `analytic_pendulum`) explicitly solves `theta'' + (g/L)*theta = 0`; its README already states that the linearized energy, not nonlinear energy, is conserved. Thus `d/dt [L^2*omega^2/2 + g*L*theta^2/2] = omega*(L^2*theta'' + g*L*theta) = 0`. Equivalently, `theta^2 + (omega/sqrt(g/L))^2` is constant. This is derived from the specified ODE, not fitted to RK4 output.

For the same linear solution, the nonlinear energy has derivative `g*L*omega*(sin(theta)-theta)`, which is generally nonzero. Starting at angle A and zero angular velocity, the exact quarter-period has theta=0 and omega=-sqrt(g/L)*A. Its nonlinear-energy ratio to the initial value is `A^2/(4*sin(A/2)^2)`, not 1. The recovery test verifies this predicted nonzero change for signed amplitudes and two gravity/length pairs while independently checking the linear invariant at every sample. Therefore the frozen nonlinear-energy assertion `relative drift <= 1e-7` cannot be an acceptance requirement for this corrected linear domain; its two failures are retained and disclosed, not weakened or hidden. The nonlinear-only domain still checks its original nonlinear invariant.
