# Real2Simulation benchmark

## Summary (read this first)

- **What is measured:** real runs on approved, licensed clips — image-space fit precision, floor-normal
  consistency, the ST03 prefix-to-suffix prediction error (diagnostic only), GPU timings, Modal billed cost
  and Meta API tokens/latency.
- **What is simulated:** fitter/lab synthetic cases and the S20d spend-cap regression (zero provider calls,
  not spend). Simulated values are never mixed into measured rows or sums.
- **What is UNAVAILABLE:** any metre, m/s^2 or gravity *error vs truth* (no calibrated scale or capture
  clock); metric scene scale for RM02/RM04/RM05; bounce and pendulum prediction errors; the Gate RS median;
  Meta dollar cost. Each has an evidence-backed reason in the tables below.
- **Gates:** Gate M **NOT_MET_INPUT_READINESS**; Gate RS **NOT_MET**; Gate A **MET_AMENDED_Q16**
  ("scale unverified, not setup-validated") — never plain MET.
- **Honest limits:** one run per measurement (no variance claim); ST03 scored frames cover under 80% of the
  sealed suffix, so it is not a Gate RS score; the precision rows are not accuracy; costs cover
  a handful of jobs, not a production estimate. Physical/calibrated accuracy is not claimed anywhere.

App About data: [Build/web/src/about/about.json](Build/web/src/about/about.json), generated by
[Build/benchmark/about.py](Build/benchmark/about.py) from the S21 JSONs and
[evidence/S14/GATE_A.json](evidence/S14/GATE_A.json) (sha256 recorded); rendered by
[Build/web/src/about/About.jsx](Build/web/src/about/About.jsx). `test_about.py` fails if it drifts.

Status: **inputs and method frozen (S21a); results S21b-d; summary and About data S21e**.
Numbers are not written here by hand.
Every reported number is a JSON pointer into sha256-pinned accepted evidence,
listed in [Build/benchmark/manifest.json](Build/benchmark/manifest.json) and resolved by

## Gates (honest status)

- **Gate M: NOT_MET** (no calibrated scale or capture clock). No metre or m/s^2 claim.
- **Gate RS: NOT_MET** (no category reaches 80% scored coverage; median unavailable).
- **Gate A: MET_AMENDED_Q16**, labelled "scale unverified, not setup-validated" (S14h checkpoint; inputs were
  recorded-scene fixtures, synthetic interview answers and synthetic-room trial tools; open known limits listed
  in GATE_A.json).
- Gate M/RS are read from evidence pointers and Gate A from its checkpoint, not asserted here.

## Method

1. **Inputs.** Only accepted evidence from S05d (floor/gravity/scale), S06e/f/h (scene runtime and
   billed cost), S07b orch14 (ST03 prefix tracking), S11 (fitter, simulated), S12 (Gate RS, ST03
   prediction). Library UI is not an input (controller decision: S18 dependency relaxed).
   No new GPU or API runs.
2. **Clips.** ST03 (projectile, Pexels License), BN01 (bounce, not scored), PD02/PD03/PD04/PD06
   (pendulum, not scored), RM02/RM04/RM05 (scene). Licence and approval receipts via pointers.
3. **Metric for S12 (Q15=A).** Scale-free error: per-clip RMS of |y_pred - y_obs| divided by image
   height over the sealed held-out suffix; Gate RS uses the median over categories. Units:
   image-height fraction. Not a physical accuracy claim.
4. **Split.** ST03 training prefix = tracked frames up to the sealed last training frame;
   held-out = the sealed suffix in the committed prediction trace. Scored frames = tracked
   suffix frames after the boundary.
5. **Automated leakage check** (`leakage()` in manifest.py), fails if any of:
   train/held-out overlap; max(train) >= min(held-out); boundary, prediction and Gate RS disagree on
   the last training frame; counts differ from the seal; scored frames fall outside the sealed suffix;
   training or prediction sha256 differ across evidence; the prediction records reading suffix
   observations at fit time.
6. **Classes.** *measured* = real run on approved licensed input (image-derived or billed);
   *simulated* = synthetic/analytic; *unavailable* = evidence value is null/abstained, with an
   evidence-backed reason. The validator rejects any literal number in gates/clips/split/metrics.
7. **Estimates vs billed.** Cost rows are labelled `USD (billed)` or `USD (estimate, not billed)`;
   cold start and inference are separate timing rows. One run each: no variance claimed.

## What is unavailable (and why, per evidence)

- Calibrated gravity magnitude and gravity error in m/s^2 (Gate M).
- Metric scene scale for RM02/RM04/RM05 (S05d abstained: no source-backed known-size reference).
- Gate RS median; bounce and pendulum normalized RMS (no prefix tracking / sourced records).
- The ST03 normalized RMS is measured but **diagnostic only** (coverage below 80%; `scored=false`).
- Meta Model API dollar cost for the S16e call (tokens measured; pricing unverified, Q17).

## Reproduce

`python -B -m unittest discover -s Build/benchmark -p "test_*.py"` re-checks pins, leakage, every table above
and the About data. After any evidence change, rerun the generators (`errors.py`, `predictions.py`,
`costs.py`, `about.py`); a sha mismatch means the freeze must be redone, not edited.

Pitch-number cross-check (S21f): `python Build/benchmark/crosscheck.py` re-checks every table row, prose decimal,
count claim and gate label here, plus about.json rows and About.jsx (no typed numbers; SWC compile in
`test_crosscheck.py`), against the S21 JSONs and GATE_A.json; frozen output
[evidence/S21/crosscheck.json](evidence/S21/crosscheck.json). Not done here: mounting About.jsx on an app route
(it is currently unmounted); pitch deck/video text (not yet written) must be re-checked when it exists.
