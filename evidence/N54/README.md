`shell-check.cjs`: real workspace SSR fixture and live DEV sign-in with proposed CSS at 375, 1280, 1920 and 2560. Workspace preserves full-bleed layout and its intentionally hidden footer. No authenticated private-room E2E claim.

Both scripts launch installed Playwright Chromium headed, never Chrome. Set these environment variables to installed paths, then run from the worktree root:

```powershell
$env:PLAYWRIGHT_MODULE='C:/Users/HP/AppData/Roaming/npm/node_modules/@playwright/mcp/node_modules/playwright'
$env:CHROMIUM_EXECUTABLE='C:/Users/HP/AppData/Local/ms-playwright/chromium-1248/chrome-win64/chrome.exe'
node evidence/N54/capture.cjs before https://real2simulation.up.railway.app
node evidence/N54/capture.cjs after http://localhost:3054
node evidence/N54/shell-check.cjs
```
