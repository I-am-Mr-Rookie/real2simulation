Scope: Build/web/src/viewer/three-renderer.mjs (pause/resume), README; tests/viewer/three-renderer.test.mjs (+1 test, fake document
visibility + IntersectionObserver, updated live-resource counts), browser-smoke.html (offscreen pause check).
Synthetic S05a fixture only. **No fps, battery, real-device, measured/simulated or gate claim.**

## Behaviour

- Idle: already on-demand since S09b (no rAF loop); re-asserted (pendingFrame false when idle, idleFrames 0 in browser).
- Hidden tab (Page Visibility) or offscreen host (IntersectionObserver) → paused: invalidate only marks dirty, pending frame cancelled,
  playback clock frozen. Resume → one redraw if dirty, none if clean; playback continues from the paused time. Mounted hidden → first frame waits.
- Dispose removes the visibilitychange listener and disconnects the IntersectionObserver.
