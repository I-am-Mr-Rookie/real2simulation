- Deterministic: pure function, frozen output, same device → deep-equal budget; decimation is index-stride based. Verified.

## Limits

Budget is a heuristic from device facts, not measured fps. Emulated DPR/width in headless SwiftShader, not a real phone/GPU.
Fixture has 8 points, so decimation in the browser path is not exercised (covered by node tests). mobile_asset_id not loaded;
budget not re-evaluated on resize; decimated clouds keep the same point size.
