## Requirements
1. Modern SaaS look (references: Linear, Vercel, Raycast, Supabase dashboards; Mobbin "dashboard"/"dark mode" searches): neutral surfaces with subtle 1px borders and soft elevation, one accent colour, consistent 4/8px spacing scale, 8-12px radii, crisp type scale (Inter-like sans + mono for numbers), no hard black offset shadows, no paper texture.
2. Dark mode: first-class light + dark themes from one token set (CSS variables); default follows prefers-color-scheme; a visible theme toggle (System / Light / Dark) persisted in localStorage; no flash of wrong theme on load; contrast WCAG AA in both.
3. Less text: tool rows, rail panes, buttons and helper copy become icon + short label (details in tooltip/secondary line only where needed). Mandatory evidence labels (RECORDED / SIMULATED / what-if / scale unverified / owner clip / Held-out caveat / FIXTURE) stay VISIBLE and verbatim - they may be restyled as compact badges/callouts but never hidden or reworded.
4. More icons: one consistent icon set across rail, header, tools, stages, buttons, empty states.
5. Logo: generated by a GPT-6.1 Sol high worker with the best available image model and a proper prompt; original mark (no Meta/third-party marks); used in header, favicon and PWA icons (light + dark legible).
